How does an agent choose how to solve a problem?

The value-of-time task gives the agent several defensible ways to answer. The central object is not its average dollar value—it is the association it forms between a new question and a remembered episode.

1
Can one memory enter the answer?
Establish that the manipulation works, and see how different kinds of memories are represented.
2
Which memory wins when several are available?
Hold the memory pair fixed and change the question; inspect the specific question–memory associations.
3
What do the traces reveal about selection?
Separate information the model computes or mentions from information that actually determines the answer.
The main question

Does the agent retrieve the closest episode, default to an easy plausible rate, or construct a different representation of the person?

What Stage 1 establishes

  • The agent can use a single autobiographical memory far outside its original context.
  • The same mathematical object—a bound on $/hour—can be encoded as a price or as a personality trait.
  • Therefore Stage 2 is not only a contest among numbers. It is a contest among problem representations.

Aggregate winner rates hide the phenomenon. The informative unit is a particular pair of memories observed across the ten questions.

Important: only two calls per question.

Each exact pair has 20 calls total: ten questions × two repetitions. A “split” cell is literally one call for each memory, so question-level differences are suggestive rather than stable estimates. The larger memory ladders contain additional calls where the pair co-occurs, but other competing memories also change, so those are not clean replications of the two-memory contest.

The pattern across these combinations

Exact episodic matches are real.Rideshare retrieves Lyft; theme park retrieves Disney; bookshelf assembly often retrieves the cleaner.
When there is no close match, the agent does not abstain.It often exports whichever memory offers a simple, plausible hourly rate—especially Disney’s $15/h or the cleaner’s $20/h.
Similarity is not a single distance.Two “travel” memories can behave differently across rideshare, flight, and train questions; a chores memory can beat a wage on a work question.

Trace lesson

Use traces to identify the candidate representations and the story the model tells about them. Use changes in the final answer—and fixed-pair comparisons—to infer which representation actually controlled the solution.

Presentation takeaway

The agent is selecting a way to think, not estimating one stable parameter

A new question activates one remembered episode, and that episode supplies either an exchange rate, a character trait, or a default anchor. The closest context sometimes wins—but simple, plausible memories can become general-purpose schemas.

This is why the strongest evidence is the specific combination: with the same two memories available, which question retrieves which one, and where does the association fail?

What we can and cannot claim

  • Can: show that a single memory changes the solution; identify question-specific retrieval in several pairs; show systematic fallback to reusable memories.
  • Cannot yet: separate semantic similarity from easy arithmetic and proximity to the model’s prior.
  • Small cells: five draws per single-memory question and two per pair-question cell.
  • One system: one persona and one Qwen3-8B configuration; no human comparison yet.
  • Trace coding: keyword-based and descriptive, not a causal readout.
